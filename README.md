## 🚀 About This Project

This repository contains my personal portfolio website, engineered to showcase my expertise in AI-integrated workflows, full-stack applications, and interactive UI/UX design.

The portfolio is built as a single-page React application, featuring dynamic "terminal gates" to unlock sections, dark/light mode theming, and an interactive 3D particle hero section.

### 🌟 Key Features

- **Dynamic Active Section Tracking**: The glassmorphic navigation bar intelligently highlights the active section with a glowing text-shadow as you scroll down the page.
- **Interactive Section Gates**: Simulated terminal commands require user interaction to "unlock" professional data like projects, skills, and experience.
- **Immersive Theming**: Fully responsive Dark and Light modes mapped to visually distinct palettes (Zinc and Neutral/Sky).
- **Responsive "Card Deck" UI**: The project showcase features an interactive UI simulation that walks users through application steps (e.g., CivicAssist workflows).
- **Modern Tech Stack**: Built with Vite, React 19, TypeScript, and styled with Tailwind CSS v4.
